# Рассчёт синуса 

Этот скрипт на Python вычисляет приближенное значение синуса угла в диапазоне от 0° до 90°, используя историческую **формулу Бхаскары I** (VII век). 

Главная особенность реализации — **экстремальная вычислительная оптимизация** для систем с ограниченными ресурсами.

## ⚡ Оптимизация и преимущества метода

В отличие от стандартного вычисления синуса через разложение в ряд Тейлора (который обычно используется в программных библиотеках), данный алгоритм обладает рядом критических преимуществ:

* **Полное отсутствие факториалов:** Вычисление факториалов (особенно для больших порядков точности) требует тяжелых циклов и перегружает процессор. Здесь они не используются вообще.
* **Базовая арифметика:** Для расчета требуются только **3 операции умножения, 2 вычитания и 1 деление**. 
* **Отсутствие тяжелых библиотек:** Скрипту не нужен модуль `math` или сложные C-расширения. Весь расчет идет на уровне базовых типов данных.
* **Высокая точность при минимуме затрат:** Максимальная абсолютная погрешность формулы на интервале [0°, 90°] составляет всего **~0.0016**, что делает её идеальной для быстрых инженерных расчетов, микроконтроллеров и GameDev-интенсивных вычислений, где критически важна скорость работы Core CPU.

## 🚀 Как это работает

Для угла \(x\) в градусах применяется рациональное приближение:

\[\sin(x) \approx \frac{4x(180 - x)}{40500 - x(180 - x)}\]

Выражение \(x(180 - x)\) вычисляется один раз в числителе, что позволяет повторно использовать результат в знаменателе, сокращая количество тактов процессора на вычисления.

## 📋 Требования

* **Python 3.x** (внешние зависимости отсутствуют).

## 💻 Использование

Запустите скрипт через терминал:

```bash
python accurate_sine.py
```

### Примеры работы:

**Пример 1 (Точный расчет для 30°):**
```text
Введите угол в градусах (от 0 до 90): 30
Точный синус (аппроксимация) для 30.0° равен: 0.5000
```

**Пример 2 (Ошибка диапазона):**
```text
Введите угол в градусах (от 0 до 90): 120
Ошибка: введите число строго от 0 до 90 градусов.
```
